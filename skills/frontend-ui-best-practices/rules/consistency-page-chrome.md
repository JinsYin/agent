## 页面基础元素

- 每个页面都要有 **favicon**
- 每个页面都要有 logo
- 列表页在右上角显示总条数
- 顶栏右上角显示用户头像并提供登出入口

缺 favicon 在多标签场景下代价具体：用户开了十几个标签时靠图标定位，没有图标的标签只能逐个点开找。

创建/编辑表单必须**标记必填字段**；code、password 这类特殊字段用 placeholder 说明规则（如"6-20 位字母或数字"），不要等用户提交后才用错误信息告知。

下拉选择用可搜索的自定义菜单，并默认展示全部选项——原生 `select` 在选项超过十几个时无法检索。
