## 日期与数字格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 日期 | `YYYY-MM-DD` | `2026-04-23` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` | `2026-04-23 09:00:00` |
| 数字 | **不加千分位逗号** | `1234567` |

日期用 ISO 顺序而非 `04/23/2026`——后者在不同地区会被读成 4 月 23 日或 23 月（无效），是跨区协作中最常见的误读源。

数字不加逗号分隔的原因：这些数值经常需要被复制到 Excel 或接口调试工具里，带逗号会破坏解析。若某处确实需要千分位提升可读性，应作为该处的显式例外，而不是全局默认。
