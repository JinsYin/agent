## 分页控件必须开窗，不得全量渲染页码

页码需开窗显示：**始终显示首页与末页**，当前页及其左右各 1 页，中间断档处放**不可点击**的省略号。

```
< 1 … 49 50 51 … 103 >
```

全量渲染的问题不只是难看——103 页就是 103 个 DOM 节点和事件监听，数据量再大一个量级时页面直接卡死，而这在开发环境的几十条测试数据下永远暴露不出来。

省略号必须不可点击。做成可点击（跳转到中间某页）会让用户以为那是个明确的页码，实际跳到哪完全无法预期。

列表页必须分页，并在**右上角显示总条数**——用户需要知道结果集有多大才能决定是翻页还是改用筛选。
