## 中文与数字之间加空格

中文字符与阿拉伯数字紧贴时，字形密度骤变，读者需要额外一次视觉停顿来切分。加一个半角空格即可消除。

**错误：**

```markdown
迁移在2024年完成，共28条规则，耗时3天。
```

**正确：**

```markdown
迁移在 2024 年完成，共 28 条规则，耗时 3 天。
```

**例外**：数字与紧随其后的量词、单位若构成固定搭配，且中间无中文（如 `3ms`、`8GB`、`第 3 章` 中的"第"字后不加），按可读性判断，不必机械插空格。

行内代码同理：`共 28 条` 中若 `28` 写成 `` `28` ``，反引号外侧仍需空格。
