## 中文句子使用中文标点

中文全角标点自带字符间距，与中文字形宽度匹配；混用半角标点会让行内节奏突然变紧，且逗号、句号在中文语境下几乎贴到前一个字上。

| 用 | 不用 |
|---|---|
| `，` `。` `！` `？` | `,` `.` `!` `?` |
| `（）` `《》` | `()` `<>` |
| `、`（并列） | `/` |

**错误：**

```markdown
这条规则有三个前提: 已安装 Node(版本 20+), 已配置代理, 且网络可达.
```

**正确：**

```markdown
这条规则有三个前提：已安装 Node（版本 20+）、已配置代理，且网络可达。
```

**例外**：纯英文句子、代码、路径、命令、以及行内代码块内部一律保持半角。判据是**这一段的主语言是什么**，不是整篇文档是什么。
