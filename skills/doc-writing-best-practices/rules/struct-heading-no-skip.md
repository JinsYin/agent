## 标题层级不跳级，一篇只有一个 H1

H1 之后直接跳到 H3，在渲染上"看起来"只是字号差异，但目录生成器、锚点导航、以及把文档喂给检索系统的工具都依赖层级推断从属关系——跳级会让 H3 被挂到错误的父节点下。

**错误：**

```markdown
# 部署指南

### 前置条件      ← 跳过了 H2

## 步骤
```

**正确：**

```markdown
# 部署指南

## 前置条件

## 步骤

### 步骤一：构建镜像
```

一篇文档只应有一个 H1，即文档标题。用 H1 做章节分隔会让文档看起来像多篇拼接。

**层级深度控制在 H4 以内。** 需要 H5、H6 通常说明这一节该拆成独立文档了——读者在第四层已经很难保持对上下文的记忆。
